📚 About SecureCrypt

Understanding the cryptography and steganography powering this system.

🔐
What is Cryptography?

Cryptography is the science of protecting the content of information. It transforms readable plaintext into unreadable ciphertext using a mathematical algorithm and a key. Without the correct key, the ciphertext is computationally infeasible to reverse.

SecureCrypt uses AES-256-GCM — the Advanced Encryption Standard in Galois/Counter Mode with a 256-bit key. GCM provides:

  • 🔒 Confidentiality — data cannot be read without the key
  • ✅ Integrity — any modification is detected
  • 🏅 Authenticity — the ciphertext cannot be forged
🎨
What is Steganography?

Steganography is the science of hiding the existence of information. Unlike cryptography which obscures content, steganography conceals the fact that a message exists at all.

SecureCrypt uses Least Significant Bit (LSB) steganography: the least significant bit of each pixel channel value is replaced with a bit from the payload. This 1-bit change is imperceptible to the human eye but can carry a full encrypted message.

🛡️ Dual-Layer Security

Cryptography alone protects what the message says — but an attacker knows a secret message exists. Steganography alone hides that a message exists — but if discovered, it's readable.

Combined: an attacker cannot read the message (AES-256-GCM), and ideally does not know a message is present (LSB steganography). This provides confidentiality + concealment.

🔑
PBKDF2 — Key Derivation

Passwords are rarely suitable as direct cryptographic keys (too short, predictable patterns). PBKDF2-HMAC-SHA256 (Password-Based Key Derivation Function 2) solves this by:

  • 🎲 Adding a random salt to prevent rainbow table attacks
  • ⏱️ Applying 600,000 iterations to slow brute-force attacks
  • 📏 Stretching any password to a precise 256-bit AES key
Password + Random Salt (16 bytes)
↓ PBKDF2-HMAC-SHA256 × 600,000

🎨
Adaptive LSB — ASEE Engine

Standard LSB steganography embeds data sequentially from pixel 0. This can produce detectable patterns in smooth regions. SecureCrypt's Adaptive Secure Embedding Engine (ASEE) improves this by:

  • 📊 Computing a Laplacian texture map of the image
  • 🎯 Ranking pixels by suitability score (high texture = more suitable)
  • 📍 Embedding in textured/edge regions where LSB changes are least visible
  • 🔄 Fully deterministic — receiver reproduces the same embedding locations
🚨
Tamper Detection

AES-GCM includes a 128-bit authentication tag computed during encryption. During decryption, the tag is recomputed and compared:

  • 🔑 Wrong password → key mismatch → tag verification fails → BLOCKED
  • 🔧 Modified stego image → corrupted ciphertext → tag mismatch → BLOCKED
  • ⚠️ Both cases return the same error to avoid leaking information
ℹ️ Note: SHA-256 hashes shown in the UI are for display/analysis only. They do not authenticate the payload against an attacker who controls the image. Actual authentication comes exclusively from the AES-GCM tag.
